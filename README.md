## 🌐 Deploy to GitHub Pages

### Option A: Upload built file

1. Run:
```bash
npm run build
```
2. Upload contents of `dist/` to your GitHub repository
3. Go to:
   - Repo → **Settings** → **Pages**
4. Set:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root` or `/docs` depending on upload method
5. Save and open your Pages URL

### Option B: Deploy React source with GitHub Actions

1. Push this full source project to GitHub
2. Add a Vite GitHub Pages workflow
3. Set Pages source to **GitHub Actions**
4. Every push to `main` will rebuild and deploy

> If you want only **2 files** (`index.html` + `style.css`) for simple upload, export a static version of this design and upload those two files directly to the repository root.
